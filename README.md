# вы́Читать — Telegram-бот тестов по русскому языку

**Полноценная Mini App** для 6 вопросов с таймерами, одиночным и множественным
выбором, объяснениями, результатом, подпиской и статистикой.

## Запасной запуск в обычном браузере (20.10.2026)

Ссылка: **https://franznovii.github.io/russian-language-quiz/quiz.html**. Если Telegram не запускает Mini App, человек может открыть эту страницу в браузере и пройти те же шесть вопросов. Анонимная попытка подписана сервером и сохраняется в этом браузере; её ответы учитываются в общей статистике D1. Подписка на канал проверяется только для Telegram-пользователей. Браузерные участники увидят проценты после установленного времени, а администратор получит число участников по источникам. **В браузере невозможно гарантировать одну попытку на человека при очистке данных/смене устройства.**

Изменения подготовлены в [Worker](backend/vychitat-worker-release.js) и [Mini App](quiz.html). Достаточно один раз **обновить Worker в Cloudflare**. Детали: [пошаговая инструкция](backend/BROWSER-FALLBACK-SETUP-2026-10-20.md).

## Telegram Stories — результат картинкой (16.10.2026)

Mini App умеет создавать PNG 1080 × 1920 из персональной карточки и открывать редактор Telegram Stories с ссылкой на канал «вы́Читать». Встроенная библиотека html2canvas хранится локально в `assets/vendor/`.

Для включения **не нужны банковская карта, R2 или новые привязки**. Персональные JPEG-картинки до 700 КБ временно хранятся в уже подключённой Cloudflare D1; служебная таблица `mini_story_cards` создаётся автоматически. Требуется только обновить код Worker `vychitat` из `backend/vychitat-worker-release.js`. **Все шаги без командной строки:** [пошаговое подключение Telegram Stories](backend/TELEGRAM-STORIES-SETUP-2026-10-16.md).

## Возможности
- Шесть последовательных вопросов; на каждый 15–300 секунд (по умолчанию 60).
- До десяти вариантов ответа, возможен множественный правильный выбор.
- Одна попытка на выпуск, дедлайны проверяются сервером.
- Авторизация через подпись Telegram WebApp.initData.
- Завершившие участники видят статистику после 19:00 МСК, если подписаны
  на канал `@posttsop`. Публично только проценты, ни одного количества участников.
- В 19:00 во вторник: фиксированный срез и адресная рассылка процентов
  завершившим тест подписчикам, с учётом отправок во избежание дублей.
- Результатом можно поделиться через Telegram.
- Администратор видит подробные числа в `Cloudflare_Отчёт` Google Sheets.
- Еженедельное обновление после настройки админ-моста: заменить шесть строк в `Мини_Вопросы`, отредактировать `Мини_Комментарии`, затем в боте нажать «Подготовить выпуск» → «Опубликовать выпуск» → подтверждение. Ручная GAS-функция `cfPublishWeeklyQuiz` остаётся запасным старым способом **без загрузки комментариев**.

## Администрирование из Telegram (доработка 13.10.2026)

- Админ-клавиатура владельцу при `/start` или `/admin`: подготовить выпуск, опубликовать с подтверждением, статистика, статус.
- Комментарии к результатам 0–6 редактируются в Google Sheets → `Мини_Комментарии`; при публикации сохраняется снимок для нового выпуска.
- `/stats` пересчитывает D1, обновляет Google Sheets → `Cloudflare_Отчёт` и присылает отчёт владельцу.
- **Обязательные однократные подключения GAS, Worker и D1:** [пошаговая инструкция](backend/TELEGRAM-ADMIN-SETUP-2026-10-13.md). Сам коммит GitHub не обновляет сервер.

## Что важно перед первым публичным запуском
Код в GitHub **не устанавливает себя** в Cloudflare и GAS.
Нужно выполнить инструкции по развёртыванию.
Режим `ACCESS_MODE=pilot` предназначен только для владельца;
публичный режим нужно включить отдельно после замены тестовых вопросов.

Резервные страницы `pilot-cloudflare.html`, `pilot-cloudflare-redesign.html`,
`design-review-v7.html` не удалены: они нужны для сверки и отката.
