# вы́Читать — тесты по русскому языку

Telegram Mini App. **Сейчас только демонстрационный интерфейс**, не рабочая система голосования.

## Уже сделано
- Мобильный интерфейс для Telegram и обычного браузера.
- Шесть **примерных** вопросов, одиночный и множественный выбор.
- Проверка ответа, объяснение и итоговый счёт 0–6.
- Нет таймера и доступа к ответам других участников.
- Никакие ответы, Telegram ID и другая информация не сохраняются.

## Как опубликовать через GitHub Pages
1. Откройте **Settings → Pages** в этом репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Branch: **main**, Folder: **/(root)**, нажмите **Save**.
4. После публикации адрес будет: https://franznovii.github.io/russian-language-quiz/

Сайт можно открыть обычным браузером. Чтобы открыть его внутри Telegram, позже добавим URL через BotFather в кнопку меню бота / Web App.

## Важные ограничения демонстрации
Сейчас вопросы и ответы находятся в файле `app.js`, открытом для всех. Это **только тестовые примеры**. Нельзя использовать эти ключи для настоящего конкурса.
