# Этап 4 — проверка Telegram initData (HMAC-SHA-256)

Эта часть экспериментальная. Ни одной записи в Google Таблицы она не создаёт.

## Подготовка
1. Только в новом проекте GAS «Вычитать — Mini App» открой Project Settings → Script Properties.
2. Добавь свойство \`BOT_TOKEN\` со значением токена **того самого бота**, через который запускаем Mini App.
3. Токен никуда не пересылай, не помещай в GitHub и не вставляй в URL.
4. Если был опубликован другой токен, менять его следует согласованно: при перевыпуске старый GAS-бот перестанет работать, пока в его свойствах не заменить токен.
5. Открой в GitHub \`Stage4-TelegramAuth.gs\`, скопируй весь файл в \`Код.gs\` **нового** GAS-проекта вместо предыдущего этапа. Сохрани.
6. В редакторе GAS выбери функцию \`runAuthSelfTest\` и нажми ▶ **Выполнить**. При необходимости разреши доступ.
7. В журнале должна появиться строка \`PASS: подпись проверена, изменённые данные отклонены.\`
8. Для проверки с настоящим Telegram-клиентом обнови существующее развёртывание Web App: Manage deployments → Edit → New version → Deploy.
9. Позже открой \`telegram-auth-test.html\` через кнопку Mini App внутри Telegram, а не через внешний браузер.

Важно: подпись через HMAC рассчитывается на стороне GAS. Публичному GitHub передаётся только безопасный JS без секретов. Реальный Telegram user ID не отображается на странице, лишь проверенное сервером имя.

Для корректной проверки из Telegram сайт должен открываться по HTTPS и быть настроен как Mini App в BotFather. Не торопиться менять меню работающего бота, пока не готова новая ссылка.
