# Этап 6 — пилот Mini App: настраиваемый таймер и до 10 ответов

## Где редактировать вопросы

Для Mini App используй **только лист «Мини_Вопросы»** в таблице «вычитать_Русский язык».

**Исходный лист «Вопросы» сохранён без изменений:** его может продолжать использовать старый Telegram-бот. Не перемещай в нём столбцы до окончательного вывода старого бота из эксплуатации.

Новая структура A–Q:

| Столбец | Поле |
|---|---|
| A | № вопроса (1–6) |
| B | Когда отправить (МСК), оставлено из старой таблицы |
| C | Описание |
| D | Вопрос |
| E–N | Варианты ответа №1–10 |
| O | Номера правильных ответов, например `2,5,9` |
| P | Объяснение |
| Q | Время на ответ (сек.) |

Правила:
- Нужно **ровно шесть вопросов**, с номерами 1–6.
- От 2 до 10 вариантов, заполнять строго подряд без пустых ячеек посередине.
- Если правильных ответов несколько, в O перечисли номера через запятую. Балл даётся только за полный набор.
- Пустая Q = **60 секунд**, иначе любое целое число от **15 до 300**.
- Старые ответы, итоги и таймеры хранятся в отдельных листах — не удаляй их.
- При создании нового выпуска делается снимок вопросов: изменение листа после запуска выпуска не меняет этот выпуск.

## Установка обновлённого кода (только для будущих выпусков)

1. Открой **новый** GAS-проект «Вычитать — Mini App»; не изменяй проект старого Telegram-бота.
2. Скопируй **весь** файл `Stage6-TimedPilot.gs` в `Код.gs` этого проекта, сохрани.
3. Запусти вручную `setupMiniTimedPilot`. Ожидается:
   `PASS: новый порядок A–Q в «Мини_Вопросы» проверен. Старые листы не изменены.`
4. Обнови **существующее** Web App развёртывание: Deploy → Manage deployments → Edit → New version → Deploy. URL /exec останется прежним.
5. **Не запускай `startNewTimedPilot`, пока не готов создать следующий выпуск.** Он архивирует текущий выпуск и создаст новый из вопросов листа «Мини_Вопросы».
6. `sendTimedPilotButton` отправляет кнопку только администратору из `TEST_CHAT_ID`, URL для неё берёт из свойства `MINI_WEBAPP_URL`.

## Что уже работает в пилоте
- Проверка Telegram initData и доступ только администратору
- Индивидуальные попытки с записью каждого ответа
- Таймер на стороне GAS, который не сбрасывается при закрытии приложения
- Оценка полного набора правильных ответов
- Только проценты в общей статистике без минимальных порогов

## Что ещё не готово для публичного запуска
- Массовый доступ подписчиков вместо ограничения на TEST_CHAT_ID
- Автоматический запуск еженедельного выпуска и удобное администрирование
- Рассылка общей статистики в 19:00 и учёт уже отправленных сообщений
- Финальный дизайн, групповой нагрузочный тест и проверка домена

Не публикуй в GitHub токен Telegram, правильные ответы или данные участников.
