## A. Сегодня — закончить технику, не открывая публичный доступ

### 1. Создать 2 дополнительные таблицы D1
Cloudflare → D1 → `vychitat-quiz-db` → Console.
Открой `backend/mini-stats-migration.sql`. Выполни отдельно каждый из
`CREATE TABLE IF NOT EXISTS` и `CREATE INDEX IF NOT EXISTS`.
Это хранение неизменного вечернего среза и защиты от повторных рассылок.
Старые семь таблиц Mini App и результаты не удалять.

### 2. Обновить Worker
Cloudflare → Workers & Pages → `vychitat` → Edit code.
Полностью замени JavaScript содержимым `backend/vychitat-worker-release.js`, нажми Deploy.
Убедись, что Worker по адресу https://vychitat.fr-novii.workers.dev
отвечает `vychitat Mini App: Worker + D1 OK`.
Привязку D1 `DB` и секреты `BOT_TOKEN`, `ADMIN_KEY`, `TEST_CHAT_ID`
не изменять.

### 3. Настроить закрытый режим
Cloudflare Worker → Settings → Variables and Secrets:
- `ACCESS_MODE` = `pilot` (обычная переменная);
- `INVITES_ENABLED` = `no`;
- `WEEKLY_ENABLED` = `no`;
- `STATS_PUSH_ENABLED` = `no` (пока тестируем);
- `WEBHOOK_SECRET` = **новый уникальный секрет** из 40–64 символов `A-Z a-z 0-9 _ -`, как Secret.
  Его нужно сохранить в Cloudflare, не присылать в чат.

### 4. Добавить GAS-команды
В проект «Вычитать — Mini App» добавь новый .gs файл
`MiniReleaseControl` и скопируй **весь** код из
`backend/MiniReleaseControl.gs`. Сохрани. В Script Properties добавь
`CF_RELEASE_APPROVED` со значением `YES`.
Это включает право *вручную* запускать команды, но само ничего не меняет.

### 5. Проверить настройки
В GAS вручную запусти `cfReleasePreflight`. В журнале должно быть:
- `Бот: @posttsop_test_bot`;
- `Ссылка: https://franznovii.github.io/russian-language-quiz/quiz.html`;
- `Доступ: pilot`;
- `Таблицы вечерней статистики: true`.
Наличие тестовых вопросов пока **не ошибка** в `pilot`.
Если получена ошибка, **остановись до её исправления**.

### 6. Подключить полнофункционального бота в пилоте
В GAS вручную запусти `cfReleaseInstallPrivatePilot`.
Функция сначала приватно сохранит предыдущий Telegram webhook,
затем поставит новый webhook Cloudflare и **личную** кнопку меню только владельцу.
Глобальное меню других пользователей не меняется.
Эта команда действительно меняет webhook — запускать только после пунктов 1–5.

### 7. Проверить Telegram
В GAS запусти `cfReleaseSendSelfButton`. Затем в `@posttsop_test_bot`:
- отправь `/start`, проверь, что приходит кнопка «Открыть тест»;
- открой личную кнопку меню, проверь финальный дизайн;
- пройди тест. Если он уже завершён — увидишь предыдущий результат;
- для *отдельного тестового* повторного выпуска можно вручную вызвать
  `cfActivateRepeatPilot`, но не делать этого после подготовки завтрашнего выпуска.
Проверь повторно `cfReleasePreflight`: Webhook должен быть адресом Worker,
а личное меню — `true`.

### 8. Установить вечерний Cron заранее
Cloudflare Worker → Triggers → Cron Triggers → Add Cron:
`*/5 16-21 * * 2` (UTC).
Он включается **только по вторникам с 19:00 до 00:55 МСК** с интервалом 5 минут.
Worker реально отправляет статистику только при `ACCESS_MODE=public`,
`STATS_PUSH_ENABLED=yes`, после 19:00.
Cron по вторникам утром `0 7 * * 2` **пока не нужен**:
мы будем выпускать вопросы вручную из GAS.

### ИТОГ СЕГОДНЯ
Итоговая Mini App, бот /start и личное меню работают в режиме `pilot`,
глобальные приглашения и публичный доступ выключены. **Это полноценный закрытый тест, а не публикация.**

## B. Завтра, вторник 13 октября — публичный выпуск

1. В Google Sheets открой `Мини_Вопросы`, замени шесть тестовых заданий
   на настоящие (см. формат ниже). Особое внимание столбцу C:
   сейчас там «Бла бла бла бла», это убрать.
2. Пока `ACCESS_MODE=pilot`, вручную запусти **`cfPublishWeeklyQuiz`**.
   Функция за один запуск проверит, загрузит и активирует шесть вопросов.
   В журнале должно появиться `НОВЫЙ ВЫПУСК: timed_...`.
   Архив старых ответов сохранён.
3. Через личную кнопку в Telegram проверь первый вопрос.
   Если захочешь пройти все шесть, не забудь, что это расходует твою
   единственную попытку нового выпуска (но не попытки будущих подписчиков).
4. В Cloudflare Worker → Variables установи **`ACCESS_MODE=public`**
   и **`STATS_PUSH_ENABLED=yes`**. Оставь
   `WEEKLY_ENABLED=no` и `INVITES_ENABLED=no`.
5. В GAS выполни **`cfReleasePublishMenu`**: теперь меню станет доступно всем.
   Webhook менять повторно не надо — он уже у Cloudflare.
6. GAS: **`cfReleasePreflight`**. Убедись, что:
   `Доступ: public`, `Готовность к публикации: true`,
   `Webhook: https://vychitat.fr-novii.workers.dev/telegram`,
   `Общее меню: true`, `Вечерняя рассылка: true`,
   `Таблицы вечерней статистики: true`.
7. Проверь команду `/start` с другого Telegram-аккаунта,
   если есть такая возможность. На новом аккаунте должен открываться новый выпуск,
   а не твой результат.
8. Теперь можно объявить квиз в канале:
   https://t.me/posttsop_test_bot?start=quiz

Никто из подписчиков канала не получит личное сообщение, пока не запустит бота.
По желанию позже можно импортировать старые контакты
(`cfImportMiniContacts`) и включить рассылку приглашений отдельно.

## C. Формат таблицы «Мини_Вопросы»
Каждый выпуск — **ровно шесть строк**, по одной на вопрос:
- **A:** номер вопроса, 1–6.
- **B:** дата (если используется таблицей).
- **C:** описание / длинный текст. Может быть пустым.
- **D:** короткая формулировка самого вопроса.
- **E–N:** от 2 до 10 вариантов ответов.
- **O:** номера правильных вариантов **с 1**, через запятую. Пример `2,4`.
- **P:** объяснение правильного ответа.
- **Q:** количество секунд (15–300). Пустая клетка = 60 секунд.

Вопросы могут иметь несколько правильных ответов. Для такого вопроса
участник должен выбрать **все** правильные варианты; неполный ответ неверен.
Скрипт GAS проверит формат и не опубликует тестовые «бла бла».

## D. Каждую следующую неделю — только две операции

**По понедельникам или во вторник до начала теста:**
1. Замени ровно шесть строк `Мини_Вопросы` на новые.
2. В GAS вручную запусти **`cfPublishWeeklyQuiz`**.
   Она загрузит вопросы в D1 и активирует новый выпуск.
   Если вопросы не изменились, новый выпуск не создастся.
   Текущее состояние `ACCESS_MODE=public` менять не нужно.
   `/start` и меню остаются настроенными.

После запуска новый выпуск **сразу доступен** пользователям бота.
Для публикации по расписанию запускай функцию в нужное время,
а не накануне вечером.

**Вечером во вторник, в 19:00 МСК:**
- Cron автоматически фиксирует снимок статистики и отправляет
  **только проценты** завершившим тест подписчикам канала.
  Никому не показываются абсолютные количества, без минимального порога участников.
- Для каждой пары `выпуск × участник` сообщение отправляется один раз.
- При нехватке времени на всех получателей Cron продолжает обработку
  каждые пять минут (до 01:00 МСК).
- Кто завершил после 19:00 или подписался позже, может открыть Mini App:
  внутри проценты обновляются по текущим данным.
- Администратор обновляет `Cloudflare_Отчёт` через
  `cfBuildMiniAdminReport` и получает абсолютные числа.

### Дополнительные команды
- `cfReleasePreflight`: безопасная диагностика всего контура.
- `cfBuildMiniAdminReport`: административные показатели.
- `cfReleaseSendEveningStats20`: ручное продолжение вечерних сообщений
  (по 20, после 19:00), с защитой от дублей.
- `cfReleaseInvite20`: отправить до 20 приглашений бот-контактам
  (требует `INVITES_ENABLED=yes`).
- `cfReleaseSendSelfButton`: личная тестовая кнопка финального интерфейса.
- `cfActivateRepeatPilot`: принудительный выпуск только для тестов;
  **не применять для обычного еженедельного запуска**.

### Чего НЕ включать без отдельного решения
- `WEEKLY_ENABLED=yes` вместе с ручными запусками: это может сдвинуть
  публикацию относительно твоего плана.
- Общую адресную рассылку `INVITES_ENABLED=yes`, пока не согласован список.
- Публичный `ACCESS_MODE=public`, пока не загружены настоящие шесть вопросов.

## E. Если что-то пойдёт не так
1. В Cloudflare временно установи `ACCESS_MODE=pilot`,
   `INVITES_ENABLED=no`, `STATS_PUSH_ENABLED=no`.
2. Не удаляй ответы в D1 и не меняй токен бота.
3. Прежний webhook перед переключением сохраняется
   **только в приватных Script Properties GAS** как `CF_PREVIOUS_WEBHOOK_URL`.
   Он может содержать секретный URL-параметр — не присылай его в чат.
4. Перед восстановлением старого webhook проверь его актуальность.
   Возврат меню Telegram и Webhook нужно выполнять отдельно вручную.
