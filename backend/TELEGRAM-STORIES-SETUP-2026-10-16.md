# Сториз с персональной карточкой результата — подключение Cloudflare
**Подготовлено 16.10.2026.** Все изменения кода уже внесены в GitHub. Они **не развёрнуты** в Cloudflare автоматически.

## Что готово в GitHub

- [Mini App `quiz.html`](../quiz.html): на странице «Поделиться результатом» текст варианта B **«Мой результат в тесте канала вы́Читать. А ты справишься лучше?»** и отдельная кнопка **«Поделиться в сториз»**; прежняя кнопка обычной пересылки сохранена.
- [Стили](../assets/quiz-design.css): оформление кнопки и подписи без изменений существующего плаката.
- [html2canvas](../assets/vendor/html2canvas.min.js) + [лицензия](../assets/vendor/html2canvas-LICENSE.txt): библиотека сохраняет именно текущую карточку (баллы + комментарий) без зависимости от стороннего CDN. Готовый сториз PNG имеет размер **1080 × 1920**.
- [Worker](vychitat-worker-release.js): защищённый `POST /story-upload` (только участник, который закончил активный тест; проверка Telegram initData и размера/формата PNG) и публичное чтение PNG по трудноугадываемому адресу `GET /story-media/<random>.png`.
- Файлы хранятся в **приватном** Cloudflare R2 bucket. Публичную выдачу R2, `r2.dev`, домены и секреты настраивать **не нужно**: картинку по HTTPS отдаёт уже действующий Worker `vychitat.fr-novii.workers.dev`.
- В сториз передаётся ссылка `https://t.me/posttsop` с названием «вы́Читать»; кликабельный стикер со ссылкой в сториз Telegram доступен **только Premium**. Без Premium человек всё равно может поделиться изображением: адрес блога напечатан внизу плаката.

## 1. Создай хранилище R2 (один раз)

1. Открой **https://dash.cloudflare.com/**.
2. В меню слева открой **Storage & Databases → R2 Object Storage** (иногда просто «R2»).
3. Если впервые заходишь в R2, Cloudflare может предложить включить R2 или настроить оплату; следуй подсказкам. Ничего на этом экране не удаляй.
4. Нажми **Create bucket**.
5. Впиши **ровно** `vychitat-story-cards`.
6. Location: **Automatic** (если есть). Storage class: **Standard**.
7. Нажми **Create bucket**.
8. **Не включай Public Access**, не создавай публичный `r2.dev` URL и не назначай домен.

## 2. Привяжи R2 к существующему Worker

1. Перейди в **Workers & Pages → vychitat**.
2. Открой вкладку **Settings** и раздел **Bindings** (иногда он называется **Variables and Secrets → Bindings**).
3. Выбери **Add binding → R2 bucket**.
4. В поле **Variable name** введи заглавными буквами `STORY_R2`.
5. В поле **R2 bucket** выбери `vychitat-story-cards`.
6. Сохрани привязку (Cloudflare может предложить **Save / Deploy**).
7. **Не меняй** привязку `DB`, действующие секреты `BOT_TOKEN`, `WEBHOOK_SECRET`, `TEST_CHAT_ID`, `ADMIN_KEY`, `GAS_BRIDGE_URL` и остальные переменные.

## 3. Обнови Worker

1. В Worker `vychitat` открой **Deployments** и убедись, что прежняя рабочая версия сохранена в истории — на случай отката.
2. Нажми **Edit code**. Важно: именно редактор кода, а не просмотр read-only старой версии.
3. Открой в GitHub [`backend/vychitat-worker-release.js`](vychitat-worker-release.js), нажми **Raw**, затем `Ctrl+A → Ctrl+C`.
4. Вернись в редактор Cloudflare, выдели код единственного основного JS-файла (`Ctrl+A`) и вставь новую версию (`Ctrl+V`). **Не меняй другие файлы, секреты и привязки**.
5. Нажми **Deploy**.

**Важное:** публикация кода Worker не запускает новый выпуск, не стирает ответы и не изменяет вопросы, статистику или настройки GAS. Новая возможность включается после подключения R2. Если ошибка — **Deployments → предыдущая рабочая версия → Rollback**.

## 4. Проверь в Telegram

1. Открой `@posttsop_test_bot` на мобильном Telegram, открой Mini App. Если страница не обновилась — закрой Mini App полностью и открой заново.
2. На пройденном тесте выбери **«Поделиться результатом»**.
3. На карточке должен быть твой балл и та же шутка, что на предыдущем экране. Ниже — текст варианта B и две кнопки **«Поделиться в Telegram»**, **«Поделиться в сториз»**.
4. Нажми **«Поделиться в сториз»**. Приложение сделает персональный PNG и откроет редактор сториз Telegram.
5. Убедись, что картинка и подпись верные. **Публиковать сториз необязательно** — можно закрыть редактор для проверки. Ссылка `вы́Читать` в виде кликабельного стикера доступна Telegram Premium.

Если бот пишет «Хранилище сториз ещё не подключено», проверь, что переменная binding называется **`STORY_R2`**, а не `R2`, и что после добавления привязки был Deploy.

Если ошибка создания изображения, проверь, что в GitHub Pages доступен файл `assets/vendor/html2canvas.min.js` и подождать автоматическую публикацию Pages после коммита.

## 5. Необязательная очистка старых карточек

Чтобы PNG не хранились бессрочно, открой **R2 → vychitat-story-cards → Settings → Object Lifecycle Rules → Add rule**. Укажи префикс `stories/` и действие **Delete objects after 30 days**. Сохрани.

**Важно:** поле `customMetadata.expires` в коде само по себе **не удаляет** объекты. Для автоматической очистки нужна именно Lifecycle Rule.

## Что менять не нужно

- Google Apps Script / Web App / `doPost`.
- Google Sheets или уже скрытые служебные листы.
- D1, таблицы базы и текущие записи участников.
- Telegram BotFather / webhook.
- Публичный доступ к R2 и отдельный домен.
