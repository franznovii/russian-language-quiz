# Сториз с персональной карточкой — БЕЗ R2 И БЕЗ БАНКОВСКОЙ КАРТЫ
Обновлено 16.10.2026.

## Что изменилось

Cloudflare R2 требует подключения отдельного биллинга даже при использовании бесплатного лимита. **R2 не нужен.**
Используем уже работающую базу **Cloudflare D1** (текущую привязку `DB`).
В новой версии Worker создаётся отдельная таблица `mini_story_cards` **автоматически при первом использовании сториз**, без ручных SQL-команд. Участники, вопросы, таймеры и ответы остаются нетронутыми.

- Карточка результата в Mini App отображается без изменений, под ней текст: **«Мой результат в тесте канала вы́Читать. А ты справишься лучше?»**
- Кнопка **«Поделиться в Telegram»** остаётся, добавлена **«Поделиться в сториз»**.
- При нажатии на сториз собирается JPEG **1080 × 1920** из **персонального результата и комментария**. Изображение автоматически сжимается до **700 КБ**, чтобы укладываться в лимиты D1.
- Worker проверяет авторизацию Telegram и завершение теста, сохраняет JPEG по случайному URL в отдельной таблице.
- По адресу `https://vychitat.fr-novii.workers.dev/story-media/<случайный-идентификатор>.jpg` Telegram получает изображение.
- Картинки удаляются автоматически при последующих запросах загрузки по истечении **трёх суток**; уже просроченные картинки перестают открываться сразу. Храним не больше **500** актуальных картинок для защиты основной базы.
- Повторная попытка переслать тот же балл в течение суток использует уже сохранённую картинку.
- Кликабельный виджет-ссылка на канал **только для Premium**; остальным внизу изображения выводится адрес `t.me/posttsop`.

## Единственное ручное действие

1. **Ничего не подключай в R2.** Можешь просто закрыть экран «Get started with R2».
2. Открой [Cloudflare](https://dash.cloudflare.com/) → **Workers & Pages** → `vychitat`.
3. На странице **Deployments** убедись, что сохранена прежняя работавшая версия, чтобы при необходимости откатиться.
4. Нажми **Edit code** — нужен редактор, а не read-only просмотр развёртывания.
5. Открой готовый файл [`backend/vychitat-worker-release.js`](vychitat-worker-release.js) в GitHub, нажми **Raw**, выдели и скопируй весь код.
6. В Cloudflare в основном JavaScript-файле вставь полный новый код вместо старого, нажми **Deploy**. Секреты и привязку `DB` **НЕ изменяй**. Новый Bucket, переменные, платёжные данные, GAS или миграция D1 не требуются.
7. На телефоне полностью закрой Mini App и снова открой из `@posttsop_test_bot`.
8. Открой уже пройденный результат → **Поделиться результатом** → **Поделиться в сториз**. Telegram должен открыть редактор с твоим изображением. Необязательно публиковать — можно просто проверить и выйти.

## Если что-то пошло не так

- **Новая кнопка не видна:** обнови Mini App, проверь, что GitHub Pages уже выложил обновлённый `quiz.html`.
- **Ошибка сохранения сториз:** проверь Worker `vychitat`: новая версия должна быть активной на 100%, а привязка `DB` — сохранена.
- **Ошибка БД / лимита:** D1 Free даёт до 500 МБ на одну базу и максимальный размер записи 2 МБ; сжатая карточка занимает не более примерно 1 МБ с учётом base64. Если хранение переполнено, Worker возвращает ошибку, но сам тест продолжает работать.
- **Сбой основного Worker:** в **Deployments** используй **Rollback** до предыдущей рабочей версии. Не восстанавливай всю базу D1, поскольку это может потерять ответы за время после резервной точки.

## Отличия от прежней инструкции

В этой версии **НЕ нужны**: Cloudflare R2, `STORY_R2`, Public Access R2, `STORY_PUBLIC_BASE`, отдельный домен, банковская карта, ручной SQL в D1.
