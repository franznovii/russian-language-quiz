# Браузерная версия теста — совместно с Telegram
Подготовлено: 20.10.2026.

## Что изменено
- **Прямая ссылка:** https://quiz.libera.me/quiz.html
- Если страница открыта через Telegram Mini App с корректной `initData`, используется **прежняя** авторизация Telegram ID. Подписка на канал проверяется, как раньше.
- Если страница открыта в **Chrome, Firefox, Samsung Internet и любом обычном браузере**, не требуется Telegram. При первом нажатии «Пройти тест» Worker выдаёт анонимный **HMAC-подписанный** browserToken на 365 дней; он сохраняется в localStorage. **Секрет BOT_TOKEN остаётся только на сервере.**
- Ответы, таймеры, результаты и комментарии хранятся в существующих таблицах **Cloudflare D1**. Чтобы не смешивать личность, браузерные участники используют отрицательные ID, Telegram ID остаются положительными.
- Одна попытка на выпуск сохраняется **для одного браузера, пока сохранены его данные**. Человек может получить новую попытку после очистки данных/в приватной вкладке/на другом устройстве. Это ограничение анонимной авторизации.
- Проверка подписки для браузерной версии не выполняется. После того же времени открытия статистики — **19:00 по московскому времени** в день активации выпуска — проценты по вопросам видны браузерному участнику. Общая статистика включает обе категории пользователей.
- Административная команда **«Статистика»** присылает распределение участников: Telegram / браузер, начавших и завершивших. Данные в листе **Cloudflare_Отчёт** остаются общими для всех.
- На браузерной версии можно поделиться результатом через стандартную ссылку Telegram. Кнопка «Поделиться в сториз» скрыта, потому что нативный редактор Telegram Stories доступен только внутри Telegram Mini App.
- **Не нужны** новые таблицы, миграции, R2, оплата, новые ключи, другой бот или изменение GAS.

## Единственное ручное действие для владельца

1. Открой Cloudflare → **Workers & Pages → vychitat**.
2. Убедись, что в Deployments есть предыдущая работающая версия для отката.
3. Нажми **Edit code** (не read-only просмотр).
4. Открой GitHub: https://github.com/franznovii/russian-language-quiz/blob/main/backend/vychitat-worker-release.js
5. Нажми **Raw**, скопируй всё и замени код основного JavaScript файла Worker. Нажми **Deploy**.
6. **Не изменяй** секреты и переменные Worker, привязку базы D1 `DB`, GAS, Google Sheets и BotFather.
7. GitHub Pages публикует обновлённый `quiz.html` из репозитория автоматически (при штатной настройке Pages). После публикации полностью закрой страницу/браузер и открой по прямой ссылке.
8. В обычном браузере нажми **«Пройти тест»**. Должны показаться шесть вопросов. Ты можешь проверить поведение без необходимости действительно проходить тест до конца: открытие самой страницы не портит данные Telegram-аккаунта.
9. В Telegram Mini App отдельно проверь обычную кнопку «Открыть тест». Существующее прохождение не сбрасывается.
10. После теста нажми **«Статистика»** в админ-меню бота: теперь там есть разделение по источнику участников.

## Важные предосторожности

- Браузерный участник и тот же человек в Telegram могут считаться **двумя разными участниками**. Без Telegram ID технически невозможно надёжно связать две попытки.
- Если считать каждое открытие как уникального человека, полностью исключить повторные браузерные прохождения нельзя. Именно поэтому браузер — запасной канал доступа.
- Ограничение доступности вопросов сервером, таймеры и оценивание ответов сохраняются.
- При Deploy текущие ответы подписчиков не удаляются, выпуск не публикуется заново.
- Если Worker перестал работать — **Deployments → Rollback** к предыдущей версии; не восстанавливай всю базу D1.
