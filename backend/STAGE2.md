# Этап 2 — чтение вопросов Google Sheets без изменения действующего бота

Файл `Stage2-ReadOnly.gs` — полный код для **нового отдельного** проекта GAS «Вычитать — Mini App». Он заменяет тестовый `BridgeProbe.gs` целиком, а не добавляется вторым файлом с `doGet`/`doPost`.

## Один раз настроить доступ к таблице

1. Открыть новый проект GAS «Вычитать — Mini App».
2. В **Project Settings → Script Properties** добавить:
   - Property: `QUIZ_SHEET_ID`
   - Value: ID Google Таблицы «вычитать_Русский язык», между `/d/` и `/edit` в её адресе.
3. В `Код.gs` заменить весь текст на содержимое `Stage2-ReadOnly.gs`; сохранить.
4. В **Deploy → Manage deployments** отредактировать текущее Web App deployment (карандаш), выбрать **New version**, нажать **Deploy**. Использовать прежний URL `/exec`.
5. Открыть `questions-preview.html` на GitHub Pages, вставить URL GAS, нажать «Загрузить вопросы».

## Что проверяем

Будут показаны шесть вопросов, их текст/описание и варианты ответа. Данные берутся из листа `Вопросы` текущей таблицы. Поля «Правильные» и «Объяснение» **не уходят** на клиент.

Это **только временное чтение**: публичный GET пока не проверяет, открыт ли Mini App в Telegram. Поэтому не загружать секретные будущие тесты, пока мы не реализуем проверку Telegram initData и контроль доступа. Любой, у кого есть URL GAS, сможет получить тексты заданий (но не ключи). Никаких записей в таблицу нет.

Важное: если Google попросит разрешение `Google Sheets`, его надо предоставить новому GAS-проекту. Действующий GAS-бот по-прежнему отдельно работает и не меняется.
