# Отправка одноразовой кнопки только владельцу

Этот дополнительный файл нужен для теста Telegram initData **с реальным Telegram-пользователем**.

1. В новом проекте GAS «Вычитать — Mini App» должен стоять Stage4-TelegramAuth.gs и успешно пройти runAuthSelfTest.
2. Найди свой цифровой ID Telegram (например, в листе «Участники» рабочего бота, если ты уже зарегистрирован в нём).
3. В новом GAS Project Settings → Script Properties добавь:
   - `TEST_CHAT_ID` — твой Telegram ID (только цифры).
4. В конец `Код.gs` нового GAS вставь файл `SendAuthTestButton.gs` целиком, **не заменяя** текущий код.
5. Сохрани. В выпадающем списке функций выбери `sendAuthTestButton` и нажми ▶ «Выполнить».
6. При первом запуске Google может запросить доступ к внешним запросам; это требуется для Telegram Bot API.
7. В личном чате с действующим ботом появится одноразовое сообщение с кнопкой «Открыть проверку Mini App».
8. Нажми кнопку **изнутри Telegram**. Откроется `telegram-auth-test.html`; туда вставь текущий URL GAS /exec, нажми «Проверить Telegram». При корректной подписи увидишь своё подтверждённое имя.

Бот не меняет никакие команды/меню, не получает новую подписку, не читает getUpdates и не отправляет кнопку другим людям.

**Важно**: ссылка с GitHub Pages после подключения custom domain может автоматически переадресовать на `quiz.libera.me`. Если домен пока недоступен, сначала дождись его доступности; не меняй DNS ради теста приложения. Никакие секреты через GitHub и через чат не передаются.

Утилита рассчитана на однократный ручной запуск. Она не добавляет триггеры. После проверки `TEST_CHAT_ID` можно удалить из свойств GAS.

Реализация: https://core.telegram.org/bots/webapps#inline-button-mini-apps
