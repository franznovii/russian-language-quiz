# «вы́Читать» — Mini App, финальная логика перед дизайном

## Что уже согласовано и реализовано

- **Шесть вопросов доступны сразу**, по порядку, без задержки между ними. Колонка B не ограничивает время появления вопросов.
- Тексты будущих вопросов **не загружаются заранее**: следующий вопрос приходит с сервера только при открытии его таймера.
- Колонки только листа **«Мини_Вопросы»**: A номер, B старая дата (не используется), C описание, D вопрос, E:N варианты №1–10, O номера правильных, P объяснение, Q время.
- Каждый вопрос содержит от **2 до 10** вариантов. В O записывай `2,5,9`, если правильных три. Балл только за полный набор.
- В Q **пусто = 60 секунд**. Иначе любое целое число **15–300**. Таймер на сервере, закрытие приложения не сбрасывает его.
- Одна попытка на пользователя и выпуск; за истечение времени ставится неправильный ответ. Ответы сервер проверяет сам.
- До **19:00 МСК** закончивший видит только свой балл. После 19:00 при повторном открытии приложения видит проценты всех шести вопросов. Закончивший после 19:00 видит их сразу.
- **Нет рассылки результатов в 19:00.** Администратор публикует итоги в канале самостоятельно.
- **Предложение подписаться — сразу после завершения теста, независимо от времени.** Результат 0–6 и объяснения доступны всем. GAS немедленно проверяет подписку на вы́Читать (https://t.me/posttsop): неподписанным уже в 10:00 показываем `Подписаться на вы́Читать` и `Я подписался — проверить подписку`; подписку можно проверить до 19:00. При успешной проверке пишем: `Подписка на вы́Читать подтверждена. Общие итоги будут доступны сегодня после 19:00 МСК` (для другого дня указываем дату). **Сами проценты появляются только после 19:00 МСК**, когда подписчик снова откроет Mini App; впервые прошедший после 19:00 подписчик получает их сразу. Бот проверяет подписанные Telegram initData и членство через серверный `getChatMember` для `@posttsop`; без подписки статистика не выдаётся. Ошибки проверки не принимаются за отсутствие подписки; можно повторить запрос. Отписка снова закрывает статистику при следующем открытии.
- **Поделиться результатом** — кнопка на экране результата, создаёт сообщение с баллом и ссылкой на `@posttsop_test_bot`. Для открытия теста получатель переходит по ссылке `https://t.me/posttsop_test_bot?start=quiz` и сразу получает кнопку `Открыть тест` при запуске бота. Название канала в пользовательских строках без кавычек.
- **«Мини_Отчёт»** с числом начавших, завершивших, незавершивших, статистикой каждого вопроса и распределением 0–6. Обновление вручную функцией `buildMiniAdminReport` из отдельного файла `MiniAdminReport.gs`.
- Режим `MINI_ACCESS_MODE=pilot` (по умолчанию) разрешает вход только `TEST_CHAT_ID`. Режим `public` позволяет войти любому пользователю Telegram, открывшему Mini App из кнопки бота. Подписка на канал проверяется для выдачи общей статистики, но не для прохождения вопросов.
- Подготовлены инструменты публичного запуска: `configureMiniBotMenu` (кнопка Mini App в меню личного чата), `sendMiniInvitationsBatch` (по 20 приглашений ранее зарегистрированным активным пользователям, без повторной отправки в том же выпуске). Дополнительно реализован `installMiniTuesdayTrigger` для недельного запуска. **По умолчанию функции не отправляют сообщения** и требуют явного включения.
- Создание следующего выпуска — `startNewTimedPilot` (название сохранено для совместимости). Создаёт новый снимок шести вопросов и архивирует прежний, не стирая прошлые ответы.
- Старые листы и исходный старый Telegram-бот **не изменяются**. До реального запуска нужно отключить его прежнюю автоматическую рассылку опросов, иначе будут дубли.

## Бот как кнопка запуска (новая согласованная архитектура)

1. Новичок открывает `https://t.me/posttsop_test_bot?start=quiz`, нажимает **«Запустить»**, получает одно короткое приветствие с inline-кнопкой **«Открыть тест»**. Никто не должен искать приложение в меню.
2. Бот сохраняет Telegram ID в отдельный лист `Мини_БотКонтакты`. По повторному `/start` выдаёт такую же кнопку и обновляет дату контакта, но не создаёт дубль участника.
3. Каждый вторник при появлении нового выпуска (если специально включены `MINI_WEEKLY_ENABLED=yes` и `MINI_INVITES_ENABLED=yes`) отправляет кнопку «Открыть тест» ранее запустившим бота. Аудитория собирается из старого листа `Участники` и нового `Мини_БотКонтакты`, без дублирования сообщений в выпуске. Автоматический запуск обрабатывает до 200 контактов за срабатывание, а оставшуюся очередь отправляет автоматически через повторные одноразовые триггеры примерно раз в час (пока выпуск не старше 7 дней).
4. Никакой проверки знаний или опросов **внутри самого бота** больше не будет после миграции: только приветствие, кнопка приложения и еженедельное приглашение. Весь тест и статистика находятся в Mini App.
5. **Обработчик `/start` включён в [Stage6-TimedPilot.gs](./Stage6-TimedPilot.gs). Отдельный `MiniLauncherWebhook.gs` не устанавливай.** После отключения старых триггеров и обновления нового GAS можно переключить webhook даже в режиме `pilot`: тестовый аккаунт получит кнопку, остальные — сообщение о подготовке квиза. Команды `activateMiniLauncherWebhook` и `checkMiniLauncherWebhook` выполняются один раз при миграции; публичный доступ включается только перед настоящим выпуском.
6. В будущих пересылаемых результатах используется Bot API `savePreparedInlineMessage` плюс Telegram WebApp `shareMessage`: название канала **вы́Читать — кликабельная ссылка** на `https://t.me/posttsop`, а «Пройти тест» — ссылка на бота и отдельная кнопка. Для старых клиентов предусмотрен fallback share/url с видимыми URL. Работа подготовленного сообщения должна быть проверена внутри настоящего Telegram после обновления GAS; текущая предыдущая версия продолжает работать, пока не обновим код.
7. Прямая ссылка `?startapp` возможна только после настройки **Main Mini App** в BotFather. Она может не создавать диалог с ботом и потому сама по себе не гарантирует возможность еженедельных личных приглашений. Поэтому основной путь привлечения сейчас — `?start=quiz` → «Запустить» → «Открыть тест».

## Установка: один раз после всех правок кода

1. Открой **отдельный** GAS-проект «Вычитать — Mini App», НЕ проект старого бота.
2. Скопируй весь файл [Stage6-TimedPilot.gs](./Stage6-TimedPilot.gs) в имеющийся `Код.gs`, замени прежний текст и сохрани.
3. Файл `MiniAdminReport.gs`, уже установленный в проект, **оставь как есть**; не вставляй его второй раз в `Код.gs`.
4. В «Настройки проекта → Свойства скрипта» оставь существующие `BOT_TOKEN`, `QUIZ_SHEET_ID`, `TEST_CHAT_ID`, `MINI_WEBAPP_URL`; добавь/проверь `MINI_ACCESS_MODE` со значением **`pilot`**. Пока **не** задавай `MINI_INVITES_ENABLED=yes` и `MINI_WEEKLY_ENABLED=yes`.
5. Запусти вручную `setupMiniTimedPilot`. Она проверит структуру листа `Мини_Вопросы`; не создаёт новый выпуск и не удаляет результаты. Затем запусти вручную `checkMiniChannelSetup`: она подтвердит через Telegram, что бот видит подписку тестового аккаунта на канал вы́Читать.
6. Меню «Развернуть → Управление развертываниями → карандаш → Новая версия → Развернуть». **Редактируй существующее развертывание**, чтобы URL /exec остался прежним.
7. Открой уже полученную ранее кнопку Mini App в чате с тестовым ботом. Текущий выпуск и сохранённые результаты останутся. На результатах после 19:00 у подписанного тестового аккаунта должна появиться статистика; на неподписанном (при временном переключении в `public` и отдельном тестировании) — предложение подписаться. **Пока режим `pilot` не меняй.**
8. Когда понадобится **новый тестовый выпуск** с вопросами листа `Мини_Вопросы`, отдельно запусти `startNewTimedPilot`, затем `sendTimedPilotButton`. Это заархивирует предыдущий выпуск. До готовности нового выпуска эти функции не трогай.

## Переключение старого бота на launcher без преждевременной публикации

**Безопасно переключать webhook ещё в режиме `MINI_ACCESS_MODE=pilot`.**
- Для тестового Telegram ID команда `/start` сразу присылает кнопку **«Открыть тест»**.
- Для остальных команда `/start` сохраняет контакт на будущие рассылки, но сообщает «Новый тест пока готовится» — не выдаёт доступ к тестовым заданиям.
- Никаких еженедельных рассылок до явного включения флагов `MINI_WEEKLY_ENABLED=yes` и `MINI_INVITES_ENABLED=yes`.
- `activateMiniLauncherWebhook` сохраняет адрес прежнего webhook (если есть), переводит входящие сообщения Telegram на новый GAS и убирает старые команды бота. База и старый проект не удаляются.

Порядок миграции:
1. В **старом** проекте GAS удалить/отключить прежние триггеры опросов, чтобы они не отправляли сообщения самостоятельно. Код проекта не удалять.
2. В **новом** проекте «Вычитать — Mini App» заменить `Код.gs` последним `Stage6-TimedPilot.gs` и обновить существующее развёртывание `/exec`. Отдельный `MiniLauncherWebhook.gs` устанавливать **не нужно**.
3. Оставить `MINI_ACCESS_MODE=pilot`, а `MINI_WEEKLY_ENABLED` и `MINI_INVITES_ENABLED` выключенными.
4. Выполнить `activateMiniLauncherWebhook`, затем `checkMiniLauncherWebhook` — в логе ожидается **«НОВЫЙ Mini App»**.
5. Отправить `/start` в Telegram и убедиться, что тестовому аккаунту приходит **«Открыть тест»**. Для остальных до публикации отображается сообщение о подготовке.
6. Только после утверждения дизайна, реальных вопросов и итоговой проверки перейти в `public` и включить приглашения/недельный триггер.

## Публичный запуск: НЕ активировать до дизайна и финального теста

1. Проверь опубликованные шесть реальных вопросов, баллы, подписку/отписку для статистики после 19:00, таймер и тест на нескольких Telegram-аккаунтах.
2. После выключения старых опросов установи Script Property `MINI_ACCESS_MODE` = `public` и запусти `configureMiniBotMenu`, чтобы в меню личного чата появилась кнопка Mini App. Обновлять развертывание из-за изменения Script Properties не нужно.
3. Для адресной отправки **только тем, кто уже общался с ботом**, отдельно установи `MINI_INVITES_ENABLED` = `yes` и вручную запусти `sendMiniInvitationsBatch`. Функция обрабатывает первые 20 получателей, затем при наличии оставшихся автоматически планирует продолжение через час; уже отправленным в том же выпуске повторно не пишет. Подписчикам канала, которые **не запускали бота**, Telegram не позволяет просто так отправить личное сообщение.
4. Никакая вечерняя рассылка здесь не предусмотрена. Для публикации статистики после 19:00 вручную запускай `buildMiniAdminReport`.
5. **Еженедельный запуск по вторникам подготовлен, но выключен.** После отключения старых опросов и проверки запуска один раз запусти `installMiniTuesdayTrigger`. Триггер срабатывает примерно в 10:00 МСК по вторникам. Чтобы он создавал новый выпуск, отдельно установи `MINI_ACCESS_MODE=public` и `MINI_WEEKLY_ENABLED=yes`. В один вторник выпуск не создаётся повторно. Если шесть вопросов не изменились по сравнению с прошлым активным выпуском, новый выпуск не создаётся и рассылки не будет. Если дополнительно задано `MINI_INVITES_ENABLED=yes`, будут отправляться утренние приглашения зарегистрированным активным пользователям бота, до 200 за срабатывание с автоматическим продолжением оставшейся очереди примерно каждый час. Никаких автоматических рассылок **результатов** нет.

## Ограничения и безопасность

- В GitHub нет токена Telegram и правильных ответов.
- История голосов старого бота и ответы пилота не стираются.
- Для работы Telegram Mini App нужна настоящая кнопка Web App в Telegram, обычный браузер не передаёт подписанные `initData`.
- Доступ к Google Таблице определяют её настройки доступа. Не публикуй таблицу целиком, иначе администраторский отчёт увидит любой, у кого есть доступ.
- GAS и Google Sheets имеют ограничения по числу одновременных выполнений. До запуска на большую аудиторию необходимо провести нагрузочное испытание.
