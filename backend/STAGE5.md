# Этап 5 — тест с настоящими ответами, только для администратора

## Какие файлы
- `Stage5-MiniPilot.gs`: **полная замена** всего кода файла `Код.gs` отдельного проекта Google Apps Script «Вычитать — Mini App».
- `../pilot-quiz.html`: интерфейс в Telegram, уже загружен в GitHub Pages.

## Защита действующего бота
НЕЛЬЗЯ заменять код старого GAS-бота. Этот этап работает **только в отдельном GAS-проекте**, созданном нами. Новые таблицы появляются в существующей Google Таблице, но листы `Вопросы`, `Участники`, `Отправки`, `Итоги` не изменяются.

## Процедура
1. Убедиться, что в свойствах **нового** GAS есть `BOT_TOKEN`, `QUIZ_SHEET_ID`, `TEST_CHAT_ID`.
2. Вставить **весь** `Stage5-MiniPilot.gs` вместо текущего `Код.gs`, сохранить.
3. В выпадающем списке функций выбрать `setupMiniPilot`; выполнить. Может потребоваться разрешить доступ к Google Таблицам. В журнале будет `PASS: пилотный выпуск создан; 6 вопросов сохранены отдельным снимком.`
4. В исходной таблице появятся три **новых** листа:
   - `Мини_Выпуски`: копия содержания шести заданий на момент запуска пилота
   - `Мини_Участники`: Telegram ID участников теста
   - `Мини_Ответы`: индивидуальные ответы и правильность
5. Обновить **существующее** развёртывание Web App: Deploy → Manage deployments → Edit → New version → Deploy (сохранить прежний /exec URL).
6. В GAS выбрать `sendMiniPilotButton` и выполнить (вручную один раз). Только в личный Telegram чат `TEST_CHAT_ID` придёт кнопка для пилота.
7. Нажать новую кнопку в Telegram. На странице ввести уже известный URL GAS /exec, нажать «Подключить тест», ответить на шесть вопросов.
8. Проверить лист `Мини_Ответы`: должно быть 6 строк ответов на одного участника. Не отправлять скриншоты с ID участника/токеном.

## Важные условия
- Пилот допускает **только** Telegram ID из свойства `TEST_CHAT_ID` (сервер проверяет подпись Telegram и сравнивает ID).
- Одна попытка на выпуск; отправленные ответы нельзя изменить. Перезапуск страницы продолжает незавершённую попытку.
- По завершении после 19:00 МСК проценты выводятся на экране. До 19:00 выводится время публикации. Абсолютные числа публично не показываются, минимального порога участников нет.
- **Массовой рассылки в 19:00 здесь пока нет.** Её добавим отдельно после проверки записи ответов, без вмешательства в действующий бот.
- Файлы GitHub Pages публичны, но ключи правильных ответов и токен Telegram в них не находятся. Объяснения и правильные варианты приходят только после сохранения ответа.
- Для новых выпусков позднее появится отдельная функция подготовки/публикации. Текущий этап рассчитан на один пилот.

## Отладка
- Тестовый GAS должен быть развернут как Web App: Execute as: Me; access: Anyone.
- Если ответ приходит с ошибкой, проверить Apps Script → Executions и свойства скрипта.
- В браузере вне Telegram тест не запустится, это ожидаемо.
- Если домен quiz.libera.me ещё не заработал, сначала завершить настройку DNS/HTTPS и только затем проверять новую кнопку. Не менять CNAME без диагностики.
